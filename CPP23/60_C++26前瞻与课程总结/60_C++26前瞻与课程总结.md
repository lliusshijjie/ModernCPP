## 一、底层原理：四个标准，一条主线

### 1.1 C++14 → 23 的进化逻辑

| 标准 | 主旋律 | 代表件（本课编号） |
|---|---|---|
| C++14 | **让写法省下来**：推导与编译期计算解放 | 泛型 lambda（01）、constexpr 增强（02）、变量模板（03） |
| C++17 | **让表达丰富起来**：语言糖 + 库地形扩展 | 结构化绑定（11）、if constexpr（13）、optional/variant/string_view（16~20） |
| C++20 | **让泛型有纪律、数据有管道** | concepts（31）、ranges（32~34）、<=>（35）、format（36）、jthread（38）、协程（39）、constexpr 容器（44） |
| C++23 | **让日常顺滑**：工效学补完 | print（49）、expected（50）、deducing this（52）、generator（54）、flat_map（57） |

一句话主线（示例 ②）：**手写类型 → 推导泛型 → 约束泛型 → 工效与安全**。
每一步都不是"新花样"，而是把上一步被迫手写的东西收编成语言/库能力。

### 1.2 毕业生自检：六课知识一条管道（示例 ①）

`generator（54）→ filter/take 视图（33）→ ranges::to（53）→
expected（50）→ print + 范围格式化（49/59）`——
课程后半段的能力在一条"偶数平方"管道里全部就位。
**能不看讲义预测示例 ① 的两行输出，这 60 课就没白学。**

## 三、C++26 前瞻与下一步

### 3.1 本机已可试的两件（姊妹文件实测通过）

- **包索引**（P2662）：`Ts...[0]` / `args...[0]`——
  第 03 课时代"递归取首类型"的技巧一行化
- **=delete 带原因**（P2573）：`void f(double) = delete("msg")`——
  误用报错自带人话说明

### 3.2 已标准化、本机未实现（如实清单）

反射（P2996，模板元编程换代）、契约（P2900，pre/post 检查）、
std::execution（P2300，结构化异步）、hazard_pointer/rcu（P2530/P2545）、
inplace_vector（P0843）——**工具链到位前，知道名字就是先发优势**。

### 3.3 毕业后的学习法（本课程的方法论）

1. **先预测再运行**——每课示例的规矩，就是 C++ 的实验方法：
   假设（预测注释）→ 实验（编译运行）→ 复盘（差异即知识点）
2. 读提案编号的习惯：每课"参考"节的 P**** 就是第一手资料
3. 本机实证的习惯：本课程两次遇到"标准有、实现无"
  （mdspan、指针格式化）与"实现先行"（flat_map）——
  **文档说了不算，编译器说了才算**

## 常见陷阱（毕业后别踩）

1. **追新弃旧**：C++26 的反射不会让 concepts/ranges 过时——
   新版本解决的是新问题，旧能力仍是地基
2. **跳过基本功直上新特性**：generator 用得溜的前提是
   第 39 课协程机制理解到位——收藏夹吃灰的特性列表一文不值
3. 单一标准洁癖：真实工程 C++14/17/20/23 并存（第 47 课前的
   代码库）——**混编共存**的阅读能力与迁移手感是硬通货
4. 忘了工具链差异：MSVC/GCC/Clang 的特性进度表各不相同
  （本课两次实测就是证据）——写跨平台代码先查 cppreference 的
   编译器支持表
