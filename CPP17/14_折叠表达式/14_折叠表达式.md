# 第 14 课 · 折叠表达式 fold expressions（C++17）

> 所需标准：**C++17** ｜ 讲解：本文件 ｜ 独立代码：`14_fold_expressions.cpp`

## 一、底层原理

### 1.1 参数包展开的原语化

第 03 课用 `dummy 数组 + 逗号表达式`、第 13 课用 `if constexpr 递归`来展开
参数包——都是变通。折叠表达式把它变成一等语法：**编译器把双目运算符
展开到包的全部元素上**，形成表达式树；语法本身无需递归辅助函数或 dummy 数组。
表达式在运行时如何求值，仍取决于实际运算符和操作数。

### 1.2 四种形式（必须整体加括号）

设包元素为 `e1 e2 e3 e4`，运算符 `op`，初值 `init`：

| 形式 | 写法 | 展开结果 |
|---|---|---|
| 一元右折叠 | `(pack op ...)` | `e1 op (e2 op (e3 op e4))` |
| 一元左折叠 | `(... op pack)` | `((e1 op e2) op e3) op e4` |
| 二元右折叠 | `(pack op ... op init)` | `e1 op (e2 op (e3 op (e4 op init)))` |
| 二元左折叠 | `(init op ... op pack)` | `(((init op e1) op e2) op e3) op e4` |

**方向改变括号结合方式，对不满足结合律的运算（`-` `/` 等）至关重要**——同一包不同方向结果不同
（示例 ① 用减法实证：右折叠 -2，左折叠 -8）。

### 1.3 空包规则

| 运算符 | 空包一元折叠的结果 |
|---|---|
| `&&` | `true`（单位元） |
| `\|\|` | `false` |
| `,` | `void()` |
| 其他（如 `+`） | **编译错误**——用二元折叠带初值解决 |

## 二、具体语法

```cpp
(xs + ...)          // 一元右折叠
(... + xs)          // 一元左折叠
(xs + ... + init)   // 二元右折叠（推荐：空包安全、意图明确）
(std::cout << ... << xs)   // 流式打印经典式
```

规则细则：

- 括号是语法的一部分，不是可选装饰
- 大多数双目运算符都可用（算术/比较/逻辑/位/逗号；完整清单见 cppreference）
- 包可以嵌在更大的表达式里：`(... && (xs > 0))` 对每个元素做判断
- 判定在**实例化期**展开——与 if constexpr 是天生一对

## 三、实际应用与最佳实践

### 3.1 场景三连（示例 ②③）

- 流式打印一串异构参数（退休第 03 课的 dummy 数组）
- 带分隔符输出：`逗号运算符 + 副作用折叠`
- 逻辑聚合：`all/any`、参数校验

### 3.2 最佳实践清单

1. 明确空包政策：sum 通常用带初值的二元折叠；内建 `&&`、`||` 的一元折叠本身也支持空包
2. 非交换运算符先想清楚方向（`-` `/` 的左/右折叠结果不同）
3. 带副作用的复杂折叠（示例的 sep 版本）控制在一行内，
   再复杂就改 `for_each_arg` 式的"调用折叠"
4. 折叠是给**参数包**用的：普通容器遍历请用 range-for；ranges 留到 C++20 第 32～34 课
5. 折叠 + if constexpr 组合是 C++17 元编程的主力搭档

## 常见陷阱

1. **忘括号**：`xs + ...` 没有外层括号直接编译错——括号是语法
2. 一元折叠遇到空包：`(... + xs)` 空包编译错误——换二元折叠带初值
3. 方向想当然：`(xs - ...)` 与 `(... - xs)` 结果不同（-2 vs -8），减法除法必查方向
4. 重载 `operator&&` 不具有内建 `&&` 的短路语义；需要短路时先把各结果转换为 bool。
5. 括号结合方式不等于副作用的求值顺序；`+` 折叠不会保证从左到右执行。
   多次修改同一对象前必须核对序列规则，不能假定括号会避免未定义行为。

## 练习

1. 用折叠表达式重写第 10 课 `print_tuple` 的"逗号分隔"逻辑
   （配合 tuple 的 get<I> 展开或 `std::apply` + 折叠）。
2. 写 `all_equal(T value, Ts... rest)`：判断后续参数是否全部等于 value，
   空包返回 true。
3. 写 `contains(value, candidates...)`，用 `(false || ... || (value == candidates))`
   判断是否有任一候选相等，并验证空包返回 false。
4. 用 `-fsyntax-only` 验证空包一元 `+` 折叠的报错文本，存档备查。
