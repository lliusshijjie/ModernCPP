# 补充 08A · 字符串与复数字面量（C++14）

> 阅读顺序：第 08 课之后、第 09 课之前；不占每日主线课编号。
> 所需标准：C++14 ｜ 独立代码：`08a_string_complex_literals.cpp`

## 一、底层原理

### 1.1 C++14 的标准字面量不止时间单位

第 08 课讲了 `2s`、`100ms` 等时间字面量。C++14 同时为字符串和复数提供了
标准后缀，使表达式直接产生相应的标准库对象。
UDL 的语言机制来自 C++11；这些标准库后缀是在 C++14 加入的。

```cpp
using namespace std::string_literals;
auto text = "hello"s; // std::string
```

没有后缀的 `"hello"` 本身是字符数组；`auto raw = "hello";` 会推导为字符指针。
带 `s` 的表达式直接返回 `std::string`，但 C++14 中的字符串构造并不因此变成编译期操作。

### 1.2 字符串后缀保留字面量长度

字面量算子接收到指针和长度，所以可以保留中间的零字符：

```cpp
std::string a = "a\0b"; // 从 C 字符串构造，size()==1
auto b = "a\0b"s;       // 明确携带长度，size()==3
```

两者的区别在于构造时采用的长度信息，而不是 `std::string` 是否支持零字符。
`std::string("a\0b", 3)` 同样可以保存全部三个字符。

### 1.3 复数后缀构造虚部

```cpp
using namespace std::complex_literals;
auto z = 1.0 + 2.0i; // complex<double>，实部 1、虚部 2
```

`2.0i` 产生实部为零、虚部为二的复数对象，再与实数相加。
这能改善数值表达式的可读性；若工程没有复数需求，了解语法和版本边界即可。

## 二、具体语法

### 2.1 字符串字面量

| 表达式 | 结果类型（C++14） |
|---|---|
| `"text"s` | `std::string` |
| `L"text"s` | `std::wstring` |
| `u"text"s` | `std::u16string` |
| `U"text"s` | `std::u32string` |
| `u8"text"s` | `std::string` |

本课不引入 C++20 的 `char8_t` 规则。C++14 中 `u8` 字面量仍使用 `char`。
使用后缀需要包含 `<string>`，并在合适的局部作用域引入 `std::string_literals`。

### 2.2 复数字面量

| 后缀 | 结果类型 |
|---|---|
| `i` | `std::complex<double>` |
| `if` | `std::complex<float>` |
| `il` | `std::complex<long double>` |

需要包含 `<complex>`，并引入 `std::complex_literals`。
字面量后缀不是普通变量名，`2i` 也不是变量 `i` 的乘法表达式。

### 2.3 两种 s 不会混成一种单位

`"5"s` 是字符串，而 `5s` 是时间长度，二者的字面量形式不同。
可以分别在局部作用域使用 `string_literals` 和 `chrono_literals`。
避免在公共头文件中使用宽泛的 `using namespace std::literals;`，
让调用点清楚说明引入的是哪组后缀。

## 三、实际应用与最佳实践

### 3.1 场景：从字符串对象开始拼接

```cpp
auto message = "user="s + "alice";
```

第一个操作数已经是 `std::string`，因此可以使用字符串拼接运算。
`"user=" + "alice"` 则不是两个 C 字符串的合法拼接方式。
后缀改善的是类型表达，不能保证任意拼接表达式都没有分配或拷贝。

### 3.2 场景：含零字节的键与数据

`"a"s` 和 `"a\0b"s` 可以作为两个不同的字符串键。
只要下游接口显式使用长度，零字符就能保留；交给只识别结尾零字符的 C API 时，
仍然会在首个零字符处结束。`payload.c_str()` 没有把数据删掉，变化的是接口解释方式。

## 常见陷阱

1. 以为 `auto text = "hello";` 得到的是 `std::string`。
2. 已经正确构造含零字符的字符串，又通过 `strlen` 计算其完整数据长度。
3. 为了方便在头文件中全局引入所有字面量命名空间。
4. 把 C++20 的 UTF-8 字符类型规则套到本课的 C++14 示例中。
5. 把标准后缀当成可自行重定义的名称；自己的字面量后缀应以下划线开头。

## 完整示例

从 `ModernCPP` 目录执行：

```bash
g++ -std=c++14 -Wall -Wextra -Wpedantic "CPP14/补充知识点/08_补充A_字符串与复数字面量/08a_string_complex_literals.cpp" -o run
```

生成后在 PowerShell 执行 `./run.exe`，在 Linux/macOS 执行 `./run`。
示例通过长度和数值打印零字符，不把原始零字节写入终端。

## 练习

1. 比较 `"x\0y"s`、`std::string("x\0y")`、`std::string("x\0y", 3)` 的长度。
2. 在不同局部作用域分别创建 `"5"s` 与 `5s`，用类型断言检查区别。
3. 把复数虚部后缀从 `i` 换为 `if`，同步调整实部类型并解释原因。
