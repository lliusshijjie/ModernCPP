# 补充 05B · 非成员迭代器与双范围算法（C++14）

> 阅读顺序：补充 05A 之后、第 06 课之前；不占每日主线课编号。
> 所需标准：C++14 ｜ 独立代码：`05b_iterator_range_tools.cpp`

## 一、底层原理

### 1.1 统一处理容器与原生数组

容器可以写 `values.cbegin()`，原生数组却没有成员函数。
C++14 的非成员工具把只读遍历和反向遍历统一起来：

| 目的 | 非成员接口 | 适用示例 |
|---|---|---|
| 只读正向遍历 | `std::cbegin` / `std::cend` | 容器、原生数组 |
| 反向遍历 | `std::rbegin` / `std::rend` | 支持反向迭代的容器、原生数组 |
| 只读反向遍历 | `std::crbegin` / `std::crend` | 支持反向迭代的容器、原生数组 |

`std::begin/end` 和标准容器的成员 `cbegin/cend` 在 C++11 已经存在。
本课的新增点是上述非成员接口，不能把它们的版本混为一谈。

### 1.2 第二个范围也需要结束位置

三迭代器版 `equal(first1, last1, first2)` 只知道第一范围的长度，要求从
`first2` 开始至少还有那么多个可读元素。它不判断第二个完整范围是否同样长。

- 第一范围为 `{1,2,3}`、第二范围为 `{1,2,3,99}`：可以合法返回 `true`，只比较前缀。
- 第二范围不足以覆盖第一范围：违反接口前提，可能越界，属于未定义行为。

所以“两个完整序列是否相等”应优先传入双方的起止位置。
这既修正了比较语义，也让算法掌握第二个范围的边界。

## 二、具体语法

### 2.1 非成员迭代器

```cpp
int values[]{1, 2, 3};
auto first = std::cbegin(values);    // const int*
auto reverse = std::rbegin(values); // reverse_iterator<int*>
```

`std::cbegin` 对象即使不是 const，也返回相应的只读迭代器。
`rbegin` 则不自动把可写对象变成只读对象；需要只读反向遍历时使用 `crbegin`。
不是所有容器都支持反向遍历，例如 `forward_list` 不适用。

### 2.2 三个双范围算法

| 算法 | 双范围形式 | 结果含义 |
|---|---|---|
| `std::equal` | `equal(f1, l1, f2, l2)` | 两范围长度相等且对应元素相等 |
| `std::mismatch` | `mismatch(f1, l1, f2, l2)` | 首个不匹配位置，或任一范围的结束位置 |
| `std::is_permutation` | `is_permutation(f1, l1, f2, l2)` | 元素及重复次数相同，允许顺序不同 |

`mismatch` 不会因为两范围长度不同就直接报告某个元素不相等。
一方先结束时，返回的某个迭代器可能等于对应的 `end`，解引用前必须检查。

### 2.3 “先检查长度”不是所有算法的统一执行步骤

随机访问迭代器能高效计算距离，`equal` 等可以利用长度直接拒绝不等的范围。
对其他迭代器，算法可以边比较边检查边界。理解接口保证即可，
不要把某个实现的检查顺序当成所有重载都遵循的步骤。

## 三、实际应用与最佳实践

### 3.1 场景：比较测试期望值与真实结果

同一段模板可以比较 `vector` 与原生数组，而不先复制为同一种容器：

```cpp
template <class Left, class Right>
bool same_records(const Left& left, const Right& right) {
    return std::equal(std::cbegin(left), std::cend(left),
                      std::cbegin(right), std::cend(right));
}
```

如果业务本来就是比较前缀，三迭代器版也有用途；调用方必须保证第二范围足够长。
优先根据业务含义选择接口，再确认迭代器和边界满足前提。

### 3.2 场景：报告首个不同字段

使用 `mismatch` 找差异后，先判断两个结果是否到达各自的结束位置：
都未结束才能读取两个不同元素；一方结束说明公共前缀相同但长度不同；
双方都结束则说明完整相等。

## 常见陷阱

1. 将三迭代器版 `equal` 的 `true` 误认为两个完整容器相等。
2. 忘记 `mismatch` 可能返回结束迭代器，直接解引用结果。
3. 把 `is_permutation` 当成集合比较；它也比较重复元素的次数。
4. 使用 C++17 的 `std::size` 或 C++20 的 Ranges 来编写本课的 C++14 示例。

## 完整示例

从 `ModernCPP` 目录执行：

```bash
g++ -std=c++14 -Wall -Wextra -Wpedantic "CPP14/补充知识点/05_补充B_非成员迭代器与双范围算法/05b_iterator_range_tools.cpp" -o run
```

生成后在 PowerShell 执行 `./run.exe`，在 Linux/macOS 执行 `./run`。
示例只演示合法的前缀比较，不执行越界案例。

## 练习

1. 把 `vector` 换为 `list`，检查哪些接口仍能使用。
2. 用 `mismatch` 区分“元素不同”“公共前缀相同但长度不同”“完全相同”。
3. 比较 `{1,1,2}` 与 `{1,2,2}`，解释 `is_permutation` 的结果。
