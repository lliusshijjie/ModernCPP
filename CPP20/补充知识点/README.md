按主线复习时，可从第 37 课开始，在读完每节主线后接着读对应的补充课。已经学完 CPP20 时，也可以先读 38A 和 45A，连着练习线程协调与配置发布。再读 37A 查整数边界，最后按 40A、41A 的顺序练习常量求值与模板实参。

每节讲解的编译命令均从 `ModernCPP` 仓库根目录执行。示例输出为 ASCII，包含边界检查。
