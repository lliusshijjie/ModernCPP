## 每课固定结构

讲解（Markdown）与代码（独立 `.cpp`）分离。讲解固定三段式：

1. **一、底层原理** —— 编译器视角：这个语法生成什么代码、解决什么旧问题、与旧写法的本质对比
2. **二、具体语法** —— 语法形式、规则细则、能做与不能做
3. **三、实际应用与最佳实践** —— 真实工程场景 + 最佳实践清单
4. 末尾附 **常见陷阱 / 练习 / 参考**

`.cpp` 示例按 `① 原理验证 → ② 语法演示 → ③ 应用实战` 三段组织，
每行输出附预测注释，输出保持 ASCII，规避 Windows 控制台编码问题。

> 说明：个别 C++20/23 特性（modules、stacktrace 等）需要额外编译选项或
> g++ 15 尚未完整支持，相应课程会给出替代验证方式并如实标注。

## 如何学习

1. 读 Markdown 讲解，理解每项特性的**动机**（它解决了什么旧问题）
2. 打开配套 `.cpp`，先**自己预测输出**，再编译运行对照
3. 完成课末练习，有疑问随时问 Claude

补充课统一存放在 [`CPP14/补充知识点/`](CPP14/补充知识点/README.md)，
使用 `02A`、`05B` 等阅读编号，每节子文件夹各自包含独立 Markdown 与 C++14 示例。
推荐按下方目录表从上到下阅读，
例如 `02 → 02A → 03 → 03A → 04`。补充课的生成不代表已经学完，
也不计入自动任务的主线完成进度；主线课程仍由现有定时任务按计划推进。

学完 C++14 前 9 课后，可阅读综合练习
[`CPP14/Practice/task_runner.cpp`](CPP14/Practice/task_runner.cpp)：
以迷你批处理任务器串联泛型 lambda、编译期计算、变量模板、元组展开、智能指针、
配置读写锁、类型推导和时间单位。文件顶部附课程对应关系与编译命令，
运行时添加 `--self-test` 可执行内置自检。

学完 C++14 第 01～10 课与 6 节补充课后，继续阅读第二个练习项目
[`CPP14/Practice/SignalWorkbench/`](CPP14/Practice/SignalWorkbench/README.md)：
以传感器采样分析台串联输入解析、名称索引、配置读写锁、独占快照、工作线程队列和类型化报告。
项目提供课程覆盖表、[逐步阅读与练习指南](CPP14/Practice/SignalWorkbench/STUDY_GUIDE.md)、
示例输入、CMake 构建入口和自检程序。两个练习的区别见
[Practice 目录](CPP14/Practice/README.md)。

## 编译运行

```bash
# g++ / MinGW-w64 / MSYS2（本机已装 g++ 15.2.0；路径含中文记得加引号）
g++ -std=c++14 -Wall -Wextra "CPP14/01_泛型lambda与初始化捕获/01_generic_lambda.cpp" -o run && ./run

# clang++
clang++ -std=c++14 -Wall "CPP14/01_泛型lambda与初始化捕获/01_generic_lambda.cpp" -o run && ./run
```

每课会标注所需的最低标准版本（`c++14` / `c++17` / `c++20` / `c++23`），
用 `-std=` 切换。本机 g++ 15.2.0 支持到 C++23（部分 C++26 特性可用 `-std=c++26`）。
